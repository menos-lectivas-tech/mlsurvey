ALTCHA · widget del captcha de prueba de trabajo
------------------------------------------------
altcha.min.js es la version 2.3.0 sin modificar, descargada de:

    https://cdn.jsdelivr.net/npm/altcha@2.3.0/dist/altcha.min.js

Proyecto: https://github.com/altcha-org/altcha (licencia MIT).

Se sirve desde aqui, como el resto de librerias de js/, para no depender
de una CDN externa. Para actualizarlo basta con sustituir el fichero por
otra version del mismo origen.

La parte de servidor (generacion y comprobacion de los retos) esta en
utils/altcha.php; los colores del widget, en css/altcha.css.
